Two related knowledge-sharing formats I run internally at
Thaumatec — one big, one small.

## SKS — SHORT KNOWLEDGE SHARING

Regular in-house training sessions, a way to share knowledge across
the organization. Presentations I've given so far:

- Dive into Containers (Docker)
- Development Environment (Windows + WSL2)
- Infrastructure as Code (Ansible)
- Self-Hosted Apps (Immich, Uptime Kuma, PiHole, Nextcloud)
- Local AI Stack (Unsloth, llama.cpp, opencode)
- ComfyUI in Practice

## sKS — SHORTER KNOWLEDGE SHARING

A shorter, lowercase form of the same idea: notes on common
problems and solutions, Linux 101 basics, and tools I've found
(mostly on Hacker News) — shared as Anki cards instead of a
presentation.
