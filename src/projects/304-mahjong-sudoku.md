Two mobile puzzle games, built for the same reason: most free
Mahjong/Sudoku apps on the stores are wall-to-wall ads. These are
the alternative I actually want to play — and an excuse to learn
Expo and React Native properly.

## MAHJONG SOLITAIRE

59 tile layouts across 6 categories, 3 difficulty levels, 6 tile
themes, light/dark mode, daily challenges, and global leaderboards
with an offline score queue. Rendered with Skia, animated with
Reanimated, state via Zustand.

## SUDOKU

Same philosophy, classic Sudoku. Per-difficulty leaderboards,
anonymous sign-in via Supabase with optional account linking, and a
Node/Express backend on Vercel serverless.

## STATUS

Both still in active development, not yet published to app stores.
