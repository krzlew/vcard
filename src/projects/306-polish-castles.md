Exploring old castles, palaces, and fortresses is a personal hobby
— this is that hobby turned into a proper interactive map.

## OVERVIEW

200+ Polish castles, palaces, and ruins plotted on an interactive
map, with accounts to track which ones you've actually visited.
Bilingual (Polish/English), seeded from Wikidata and OpenStreetMap
data with additional details enriched via Google Places.

## STACK

Next.js (App Router) with PostgreSQL via Neon and Prisma, React
Leaflet for the map, next-auth for accounts, deployed on Vercel at
its own domain.
